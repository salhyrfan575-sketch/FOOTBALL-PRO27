# Football Pro 27

A first playable 3D five-a-side football prototype built with Godot 4 for Android.

## Included in this prototype
- 5 vs 5 match on a 3D pitch
- Selectable clubs: Persepolis, Esteghlal, Real Madrid and Barcelona
- Basic 3D players, football physics and goals
- On-screen controls, passing, shooting and player switching
- Basic opponent and teammate movement
- Scoreboard, match timer and goal detection
- Low, medium and high graphics options
- GitHub Actions workflow for Android debug APK export

## Current limitations
This is an early prototype, not an EA SPORTS FC-scale production. Player models are simple procedural placeholders, not scans or likenesses of real athletes. Club names and kit-inspired colors are included, but official crests, licensed kits, realistic player faces, advanced animations, stadium crowds, commentary and sophisticated tactics are not yet implemented.

## Build an APK
Open with Godot 4.4.1 and configure Android SDK/JDK plus matching export templates, or use GitHub Actions > Build Android APK. A successful run uploads an artifact named FootballPro27-Android-APK.

## Controls
Use the on-screen arrows to move, PASS to pass, SHOOT to shoot, and SWITCH to change the controlled player. Keyboard arrows also work in the desktop editor.
